About AI Art Generator

A full-stack creative generative synthesis studio powered by Python, Flask, PyTorch, and multi-engine AI pipelines.

🎨 Architecture & Engines

This application features an adaptive multi-backend architecture designed to work seamlessly out-of-the-box without requiring complex external dependencies or paid API keys, while also supporting high-end cloud and local AI diffusion models.

⚡ Creative Neural Synthesizer

Zero-config, high-speed procedural neural synthesizer. Translates prompt semantics, harmonious color palettes, harmonic frequency fields, and style filters (cyberpunk, oil, pixel art, watercolor) in under 1 second.

🤗 Hugging Face Inference

Direct integration with Hugging Face Serverless Inference Router for cutting-edge models like FLUX.1-schnell and Stable Diffusion XL. Simply configure HF_TOKEN in .env.

🧠 OpenAI DALL-E 3

Native support for OpenAI's premier image model DALL-E 3. Enter your OPENAI_API_KEY in .env to unleash photorealistic and conceptual imagery.

🖥️ Local Stable Diffusion

Connect to local Automatic1111 WebUI or ComfyUI instances running on http://127.0.0.1:7860 with custom checkpoint models and LoRAs.

🔑 Configuring Environment Variables

To enable external cloud AI models, create or edit the .env file in the project root: 

# Hugging Face User Token (free at huggingface.co/settings/tokens)
HF_TOKEN=hf_your_token_here

# OpenAI API Key (optional for DALL-E 3)
OPENAI_API_KEY=sk-proj-your_key_here

# Local Automatic1111 WebUI URL (optional)
STABLE_DIFFUSION_API_URL=http://127.0.0.1:7860

✨ Features & Capabilities

  • ✔ Magic Prompt Enhancer: Enriches user concepts with professional lighting, medium, and aesthetic descriptors.
  • ✔ 10 Artistic Style Presets: Cyberpunk, Anime, Fantasy, Classical Oil Painting, Synthwave, Photorealistic, Watercolor, Pixel Art, 3D Octane, and Surrealism.
  • ✔ Aspect Ratio Variety: 1:1 Square, 16:9 Landscape, 9:16 Portrait, 4:3 Classic, and 3:4 Portrait.
  • ✔ Deterministic Seed Control: Reproduce exact artwork variations with fixed seeds.
  • ✔ Persistent SQLite History: Every generation is stored with metadata, searchable and filterable in the Gallery.
  • ✔ Fullscreen Lightbox & Instant Downloads: Zoom into artwork details and download high-resolution PNGs with one click.
